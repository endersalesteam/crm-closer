🌐Publicar en GitHub Pages (gratis, URL pública permanente)
Sigue estos pasos una sola vez. Después solo actualizas el archivo cuando quieras.

Paso 1 — Crear repositorio
Entra a github.com → botón verde New → nombre: crm-closer → selecciona Public → clic Create repository

Paso 2 — Subir el archivo
En la página del repositorio → clic "uploading an existing file" → arrastra CRM_Closer.html → en el campo de nombre cámbialo a index.html → clic Commit changes

Paso 3 — Activar la URL pública
Settings (arriba a la derecha del repo) → sección Pages (barra izquierda) → Branch: main → carpeta: / (root) → clic Save

Paso 4 — Tu URL estará lista en ~1 minuto:
https://TU-USUARIO.github.io/crm-closer
Comparte esa URL con tu equipo. Cada quien puede abrir el CRM desde su navegador con su contraseña.

Para actualizar el CRM en el futuro: descarga la nueva versión → ve al repo → clic en index.html → ícono de lápiz (editar) → reemplaza → Commit. Listo.
💾Sobre los datos: localStorage vs Firebase
Actualmente los datos se guardan en localStorage de cada navegador. Esto significa que:
→ Tus datos persisten aunque cierres el navegador ✓
→ Si tu socio abre el CRM en su computadora, tiene su propia copia ✓
→ Los cambios de uno no se sincronizan automáticamente con el otro ⚠

Para sincronización en tiempo real (cambios instantáneos entre todos):
1. Ve a console.firebase.google.com → Add project → crm-closer
2. Firestore Database → Create → test mode
3. Project Settings → Web app → copia el objeto firebaseConfig
4. Tu Firebase ya está configurado en este archivo ✓

⚠ Importante — Reglas de seguridad Firebase
Ve a Firebase Console → Firestore → Rules → reemplaza el contenido con:
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /crm/{document} { allow read, write: if true; } } }
Clic Publish. Esto permite que tu equipo lea y escriba datos.

Con Firebase, cualquier cambio aparece en todos los dispositivos en menos de 1 segundo.

Cambia los valores entre comillas por las que quieras. Luego vuelve a subir el archivo a GitHub.
